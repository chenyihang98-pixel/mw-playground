# 玩法和设置

## 操作

在限时内收集够宝石就赢，时间用完就输。被巡逻的守卫碰到扣 10 秒，之后 2 秒内再碰到不扣。

| 操作 | 按键 |
|---|---|
| 移动 | W / A / S / D |
| 跑 | 按住 Shift |
| 跳 | 空格 |
| 转视角 | 移动鼠标，方向键也行 |
| 暂停 / 继续 | Esc 或 P |

- 高台跳不上去，要走坡道
- 点“开始”后鼠标会锁在画面里。按 Esc 退出锁定，游戏同时暂停
- 菜单只用键盘也能操作：Tab 移动，Enter 或空格确认，Esc 关面板

## 语言

界面有中文、日语、英语三种。

- 开始界面底部和暂停菜单里各有一个语言选择。选了以后会保存并刷新页面，名册、已保存的关卡和静音设置都还在
- 游玩中要先按 Esc 暂停才能切换
- 地址后面加 `?lang=zh`、`?lang=ja`、`?lang=en`，只对这一次打开有效，不改保存的选择
- 没选过的话跟浏览器的语言走：中文浏览器显示中文，日语浏览器显示日语，其他显示英语
- 文件名、名册里的名字、已保存关卡的标题照原样显示。模型写的文字和工坊服务返回的说明，目前还是中文

## 导入角色

点“导入角色”选文件，或者把文件直接拖进窗口。

| 格式 | |
|---|---|
| `.glb` | 带骨骼和动画的角色，主要用这个 |
| `.obj` `.stl` `.ply` | 静态模型，用默认材质（OBJ 不读 MTL） |

太大的文件会先提醒，再大就不读了：

| | 提醒 | 不读 |
|---|---|---|
| 文件大小 | 超过 50 MB | 超过 150 MB |
| 三角面 | 超过 30 万 | 超过 100 万 |
| 骨骼 | | 超过 256 根 |
| 动画片段 | | 超过 64 段 |
| 贴图边长 | | 超过 8192 |

引用了外部文件的 GLB，和用了 Draco、Meshopt、KTX2 压缩的 GLB 也读不了。文件坏了只会提示导入失败，当前的主角和场景不受影响。

导入后右边出现一张卡片，在上面可以：

- 调显示身高（1.2 到 2.4 米，默认 1.75 米）。只改看起来多高，碰撞不变
- 朝向不对时左右转 90°
- 看每段动画被认成了什么（待机、走、跑、跳、其他），不对就手动改；循环还是只播一次也能改
- 动画自己带着位移时，勾上“锁定水平位移”
- “加入为新人物”放进名册，或者直接“设为主角”

缺动作时这样补：没有跑就用走加快，没有走就用跑放慢，没有待机就用走的第一帧。一个移动动作都没有（包括静态模型）时，整个模型上下晃着走。

## 名册

- 存在浏览器里（IndexedDB），最多 20 个人物。同一个文件不会加两次
- 分工有五种：主角、守卫、主角兼守卫、同伴、不出场。主角只能有一个，同伴最多 3 个
- 当守卫的人物只换关卡里守卫的外观，守卫的数量和路线不变；人不够时剩下的守卫用默认小人
- 同伴跟在主角斜后方，只和地图碰撞，不收宝石，也不会被守卫抓。落得太远会传送回来
- 同屏最多 12 个导入的角色
- 浏览器不让存的时候名册照样能用，只是关掉页面就没了

## 关卡

- **内置**：三张手工地图（草地和两个测试小关），和三关生成后固定下来的（晨光草地、沙丘黄昏、雪夜高台）
- **随机一关**：程序随机写一份说明书，生成、检查，先给预览，确认了才保存
- **已保存的关卡**：确认过的随机关卡和工坊关卡，可以加载或删除。重玩用的是存下来的布局，不重新生成

每关标着难度估计（轻松、普通、紧张）。它是拿“一路跑着收完要多久”和时间限制比出来的，守卫和绕路没算进去。

工坊做出来的关卡只让勾选的人出场。一个都不勾时，这一关没有同伴，守卫用默认小人；主角还是按名册。

## 关卡工坊

`npm run dev:workshop` 同时启动游戏（5173 端口）和工坊的本机服务（8790 端口）。服务只监听 127.0.0.1。

- 第一次生成前要先把模型加载进显存，一般几秒；长时间没用之后可能要等几十秒
- 生成中可以点“停止生成”
- 预览里能看到用的是哪个模型、一次通过还是改了几次、程序有没有调整过
- 看完预览可以“确认”“改一句话重来”或“放弃”

### 设置

用环境变量，可以写在项目根目录的 `.env` 里。

| 变量 | 默认值 | |
|---|---|---|
| `MW_LLM_PROVIDER` | `ollama` | `ollama`、`openai` 或 `off` |
| `MW_OLLAMA_BASE_URL` | `http://127.0.0.1:11434` | Ollama 的地址 |
| `MW_OLLAMA_MODEL` | `qwen3.5:9b-q4_K_M` | 模型名。不会自动下载 |
| `MW_OLLAMA_NUM_CTX` | `8192` | 上下文长度 |
| `MW_OPENAI_BASE_URL`、`MW_OPENAI_MODEL`、`MW_OPENAI_API_KEY` | 无 | OpenAI 兼容接口（只用假服务试过） |
| `MW_WORKSHOP_PORT` | `8790` | 服务端口 |
| `MW_WORKSHOP_MAX_REQUEST_CHARS` | `200` | 一句话最多几个字 |
| `MW_WORKSHOP_MAX_BODY_BYTES` | `32768` | 请求体上限 |
| `MW_WORKSHOP_CALL_TIMEOUT_MS` | `60000` | 单次模型调用的时限 |
| `MW_WORKSHOP_REQUEST_TIMEOUT_MS` | `180000` | 整个生成请求的时限 |
| `MW_WORKSHOP_PREPARE_TIMEOUT_MS` | `150000` | 加载模型的时限，不会超过整个请求的时限 |
| `MW_WORKSHOP_STATS` | `.local/workshop-stats.jsonl` | 统计文件 |

密钥只在服务进程里用，不写日志，也不返回给浏览器。统计每个请求记一行（结果、改了几次、各阶段用时），不记你写的那句话和人物信息。

## 命令

| 命令 | |
|---|---|
| `npm run dev:workshop` | 游戏加工坊服务 |
| `npm run dev` | 只有游戏。工坊会显示服务不可用 |
| `npm run build`、`npm run preview` | 正式构建和预览。正式构建连不上工坊服务 |
| `npm test` | 单元测试 |
| `npm run e2e` | Playwright 端到端测试（先运行 `npx playwright install chromium`） |
| `npm run typecheck`、`npm run lint` | 类型检查和 ESLint |
| `npm run workshop-stats` | 汇总工坊的统计 |
| `MW_WORKSHOP_ACCEPTANCE=1 npm run workshop-acceptance` | 用本机模型把 10 条固定请求跑一遍 |
| `npm run inspect-asset -- <文件> [--json]` | 看一个 GLB 的结构 |

## 看一个 GLB 里有什么

```sh
npm run inspect-asset -- path/to/character.glb
```

打印容器、网格和三角面数、贴图、骨骼，以及每段动画的名字、时长、是否循环、有没有水平位移，还有包围盒。只读这一个文件，不联网，不写文件。算不出来的项会写“未计算”和原因，不会填 0。加 `--json` 输出 JSON。

## 用自己的角色跑测试

```sh
MW_ASSET_DIR=<放角色文件的目录> npm run e2e -- tests/e2e/real-assets.spec.ts
```

把目录里的模型逐个导入一遍并截图。只读这个目录，不往项目里复制。不设 `MW_ASSET_DIR` 时这一组测试跳过。

## 开发用的网址参数

只在开发模式下有效。

| 参数 | |
|---|---|
| `?level=meadow`、`test-a`、`test-b` | 直接进手工地图 |
| `?level=gen-1`、`gen-2`、`gen-3` | 直接进三关生成的内置关卡 |
| `?view=fixtures` | 看代码生成的测试模型 |
