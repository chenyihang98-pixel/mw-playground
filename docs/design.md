# 界面和视觉的设计约定（P6）

所有界面统一用这里的约定。变量和通用组件在 `src/ui/theme.css`，图标在 `src/ui/icons.ts`，建元素和按钮的小工具在 `src/ui/dom.ts`。新增界面时先用已有的变量和组件，不要再写一套颜色和尺寸。

不用任何外部资源：

- 字体：用系统字体栈。
- 图标：手写的内联 SVG。
- 音效：WebAudio 现场合成。
- 场景：贴图是代码画的 CanvasTexture，天空是着色器渐变。

没有网络字体、CDN、下载的模型、贴图或音频。

## 原则

- 中文界面，说法直白：按钮写动作（“开始”“加入为新人物”），提示写结果和原因。
- 3D 场景是主角：界面是半透明的深色面板，压在明亮的场景上，四周留出画面。
- 同时只显示一个主面板（关卡选择、名册、导入卡片）。关卡开始面板、暂停菜单和结算是覆盖层，主面板打开时它们隐藏或让到另一侧（M7）。
- 只用键盘也能操作，焦点始终看得见。

## 色板

| 变量 | 取值 | 用途 |
|---|---|---|
| `--mw-surface` | rgba(17, 23, 33, 0.88) | 面板、顶栏、HUD 卡片的底色（背后模糊 10–12 px） |
| `--mw-surface-strong` | rgba(13, 18, 27, 0.96) | 提示条 |
| `--mw-surface-raised` | rgba(255, 255, 255, 0.06) | 面板里的小块（统计、片段、人物卡片） |
| `--mw-surface-hover` | rgba(255, 255, 255, 0.11) | 悬停 |
| `--mw-border` / `--mw-border-strong` | 9% / 18% 白 | 细边框 |
| `--mw-text` / `--mw-text-muted` / `--mw-text-subtle` | #f3f6fa / #a9b6c6 / #7c8a9c | 正文 / 次要 / 标签和注释 |
| `--mw-primary` | #3d8bff | 主要操作（开始、继续、确认、加入为新人物） |
| `--mw-accent` | #ffc845 | 宝石、主角、“设为主角”、“随机一关” |
| `--mw-success` | #3ccf8e | 同伴、检查通过、难度“轻松” |
| `--mw-danger` | #ff5d5d | 错误、扣时、删除 |
| `--mw-warning` | #ffb547 | 警告、剩余时间少 |
| `--mw-info` | #5cc1ff | 说明、恢复中 |

分工的颜色：主角金、守卫红、主角兼守卫橙、同伴绿、不出场灰（标签 `mw-tag--gold / red / orange / green / default`）。来源和难度估计也用标签：

- 来源：内置是灰色，随机是紫色，程序调整是橙色。
- 难度估计：轻松绿、普通蓝、紧张红。

## 字号、间距、圆角、阴影

| 类别 | 变量 | 取值 |
|---|---|---|
| 字号 | `--mw-text-xs / s / m / l / xl / 2xl / hero` | 12 / 13 / 14 / 16 / 20 / 28 / 46 px（开始界面的标题在大窗口里放大到最多 68 px） |
| 间距 | `--mw-space-1 … 8` | 4 / 8 / 12 / 16 / 20 / 24 / 32 px（4 的倍数） |
| 圆角 | `--mw-radius-s / m / l / pill` | 6 / 10 / 16 px / 全圆 |
| 阴影 | `--mw-shadow` / `--mw-shadow-s` | 面板 / 顶栏和 HUD 卡片 |
| 焦点 | `--mw-focus` | 2 px 深色间隔 + 2 px 金色环（#ffd76a），只在键盘操作时出现（`:focus-visible`） |

字体栈：`system-ui, -apple-system, 'Segoe UI', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', 'Noto Sans CJK SC', sans-serif`。数字用等宽数字（`tabular-nums`），计时不跳动。

## 图标

24 × 24 网格、2 px 描边、圆角线端，用 `currentColor` 着色，跟着文字颜色走。图标只做装饰（`aria-hidden`），按钮的名字由文字或 `aria-label` 提供。只有图标的按钮（关闭、静音、预览片段、删除）都有 `aria-label` 和 `title`。

## 组件

- 面板 `.mw-panel`：深色半透明、1 px 细边、16 px 圆角、大阴影。头部 `.mw-panel-header`（标题、标签、关闭按钮），正文 `.mw-panel-body`（可滚动），底部 `.mw-panel-footer`（主要操作，不随正文滚动）。
- 按钮 `.mw-btn`：
  - 默认是浅色描边；
  - `--primary` 蓝、`--accent` 金、`--danger` 红、`--ghost` 透明；
  - 尺寸 `--sm` 28 px、默认 34 px、`--lg` 46 px；
  - `.is-current` 金色描边，表示当前打开的面板或当前项。
- 标签 `.mw-tag`：22 px 高的胶囊，可带图标。
- 提示 `.mw-notice`，分三级，都带图标和左侧色条：
  - 错误：红，例如导入失败、恢复失败、存储失败；
  - 警告：橙，例如文件较大、面数多、没有移动动作只能整体摆动、设置被禁用；
  - 说明：蓝，例如兜底规则、材质说明、分配时不出场的人物。
- 表单：`.mw-input`、`.mw-select`、`.mw-range`，深色底、细边框。

## 布局

窗口四周留 16 px（`--mw-edge`）。

- 顶栏（高 48 px）：
  - 左边是游戏名和当前关卡（点开关卡选择）；
  - 右边是“导入角色”“名册”“静音”；
  - 游玩中和开始界面上不显示。
- HUD：顶部正中。
  - 剩余时间卡片：冷却期间变红，少于 15 秒变橙。
  - 收集卡片：数字和进度条。
  - 游玩中下面还有关卡名和“Esc 暂停”。
  - 守卫扣时：时间变红、屏幕边缘闪红，HUD 下方弹出“−10 秒”，冷却期间一直显示。
- 信息不截断：文件名、片段名、贴图尺寸、关卡摘要放不下时换行显示。只有顶栏里的当前关卡名会省略（悬停可看全名，开始面板、关卡选择里都有全名）。
- 主面板：从顶栏下方（`--mw-panel-top`）到窗口底部留出提示条的位置（`--mw-panel-bottom`，72 px）为止。
  - 关卡选择：居中，宽至多 940 px，左栏是内置和已保存的关卡，右栏是随机一关。
  - 名册：左侧，宽 400 px。
  - 导入卡片：右侧，宽 460 px。
- 覆盖层（开始面板、暂停菜单、结算）居中，宽至多 460 px。
  - 关卡选择打开时隐藏。
  - 名册打开时让到右边，导入卡片打开时让到左边，都不和主面板重叠，也不再盖暗整个画面。
- 提示条：底部正中，导入的状态和错误（错误有 role="alert"）。状态 6 秒后自动消失，开始游玩时清掉。
- 层级：
  - 场景；
  - 覆盖层（15）；
  - HUD（20）；
  - 顶栏（25）；
  - 开始界面（28）；
  - 主面板（30）；
  - 提示条（40）；
  - 拖放提示（50）。

1280×720 和 1920×1080 下各元素都在窗口里、两两不重叠、没有横向溢出（端到端测试按包围框检查）。窗口大小变化时画布跟着调整，HUD 保持居中。

## 页面

- 开始界面（没有 `?level=` 时先出现）：左侧一列，从左到右的深色渐变压在场景上。
  - 依次是：游戏名、一句介绍、当前关卡（来源和难度估计）、“开始”、“选关”“名册”“导入角色”“操作说明”、静音。
  - “开始”进入当前关卡的开始面板。选好一关也直接进入它的开始面板。
  - 暂停菜单的“返回开始界面”和结算的“返回”回到这里：打开着的主面板一起关掉（没加入名册的导入卡片和点“关闭”一样释放），这一关重置到开局。
- 关卡选择：每一关是一行，整行就是“加载”按钮。
  - 行里有：俯视小地图（出生时面向的方向朝上）、名字、来源、难度估计、时间 · 宝石数 · 守卫数 · 视觉预设。
  - 当前关卡金色描边。
  - 已保存的关卡右侧有删除按钮。
  - 随机一关先预览：小地图、说明书的内容、开场白、“空间与规则检查通过，难度为估计。”，再选确认、重来或放弃。
- 关卡开始面板：
  - 关卡名；
  - 标签：时间、宝石、守卫、来源、难度估计；
  - 目标；
  - 开场白、台词、默认替身的提示；
  - 可展开的操作说明；
  - “开始”。
- 暂停菜单：“继续”“重开”“返回开始界面”。
- 结算：胜利（金色奖杯）或失败（红色沙漏）。
  - 用时、收集、被守卫碰到的次数、剩余时间；
  - “重开”“返回”。
- 导入卡片：
  - 头部：文件名，以及格式、大小、带骨骼或静态模型；
  - 预览；
  - 尺寸、三角面、骨骼、片段；贴图单独占一行，逐张列出尺寸，放不下就换行；
  - 显示（身高、正前方）；
  - 提示（三级）；
  - 动作安排（待机、走、跑、跳各用什么）；
  - 片段列表；
  - 底部“设为主角”“加入为新人物”。

  没有骨骼的模型不说“绑定姿态”，说“静止姿态”（M3）。
- 名册：人物卡片。
  - 内容：缩略图、显示名（直接改，回车或 ✓ 保存）、分工标签、分工下拉框、“设置”（打开导入卡片）、删除（再确认一次）。
  - 主角的卡片金色描边，重复加入时标出的那一项蓝色描边。
  - 缩略图在运行时画出来，只放在内存里：名册恢复完以后一个一个地画，不拖慢恢复，也不写进存储。

## 键盘

- 开始界面出现时，焦点在“开始”上；开始面板和结算出现时，焦点在主要按钮上（Enter 即可）。
- 暂停菜单例外，焦点不移进去：暂停常常来自浏览器退出指针锁定的 Esc，P / Esc 照常是“继续”。按 Tab 可以进入菜单，焦点在菜单按钮上时 P / Esc 仍然是“继续”。
- 主面板打开时焦点移进面板（关卡选择是当前关卡，名册和导入卡片是关闭按钮）。Esc 关掉最上面的面板，焦点回到打开前的位置。面板打开时 Esc 只关面板，不触发暂停或继续。
- Tab 顺序就是阅读顺序。焦点环是金色的，在深色面板和明亮场景上都看得见。

## 音效

都用 WebAudio 的振荡器加包络现场合成，音量很小：

- 收集：两个上行的三角波音；
- 扣时：下滑的锯齿波和方波；
- 胜利：C–E–G–C 琶音；
- 失败：G–E–C 下行；
- 按钮：很短的 880 Hz 正弦。

AudioContext 在第一次发声时才创建，创建失败就没有声音，不影响游戏。

静音开关在顶栏和开始界面（`aria-pressed` 表示状态），存在 localStorage 的 `mw-playground:muted`。读写失败时一律按“没有静音”处理：读不到就当没有静音，写不进去时点静音也不生效（按钮的提示里说明），声音照常，游戏不受影响。

## 场景

- 光：
  - 柔和阴影（PCF）、ACES 色调映射；
  - 半球光做环境光；
  - 太阳大致从出生时镜头的后方照过来，看得见的一面不背光，影子落在物体的远侧。
- 天空：着色器做的渐变球（头顶、地平线、地平线以下），跟着镜头；地平线附近和雾的颜色一致。地图外是一大片水面（只是装饰，没有碰撞和寻路）。
- 地面：
  - 按主题画的噪点贴图（草地、沙地、雪地），细网格；
  - 地图边缘有一圈土台侧面，像漂在水上的小岛。
- 盒子和高台：
  - 顶面比侧面亮一点；
  - 盒子从同一主题的三种颜色里按 id 取一种。
- 宝石：金色，带一圈光晕；守卫的巡逻路线是地上的虚线。
- 默认小人：
  - 圆角方块拼成；
  - 主角是蓝衣金帽；
  - 守卫是红衣深色帽；
  - 显示高度等于胶囊高度（1.75 m），视觉模型挂在外层节点下的模型槽里（结构不变）。
- P5 的视觉预设（主题、时间、天气，以及雾的远近）取值不变，只是更好看；雨仍在下落。
